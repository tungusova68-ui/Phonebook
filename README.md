# Телефонный справочник

## Описание проекта
Приложение «Телефонный справочник» разработано на языке Java с использованием JavaFX.
Программа предназначена для хранения и управления информацией об абонентах и их телефонных номерах.

## Основные возможности
- Добавление новых абонентов.
- Редактирование данных абонентов.
- Удаление записей.
- Хранение нескольких телефонных номеров для одного абонента.
- Поиск абонентов по ФИО и номеру телефона.
- Сортировка записей по ФИО.
- Сохранение и загрузка данных из бинарного файла.

## Используемые технологии
- Java
- JavaFX
- Gradle
- JUnit

## Структура проекта
- `gui` — графический интерфейс приложения.
- `model` — классы модели данных.
- `service` — логика работы со справочником.
- `storage` — сохранение и загрузка данных.
- `test` — модульные тесты.

## Запуск проекта
Для запуска проекта необходимы JDK и JavaFX.
Откройте проект в IntelliJ IDEA, настройте JavaFX и запустите класс `Main`.
